Place your WSTG_Repository folder here. It is copied into every new project.

Optional: a "Settings" folder here is copied into every new project as Settings/. Put the files the tool
should never write itself in it, for example:
  Settings/Configurations/Mouse_Tool/mouse_tool.json
  Settings/Configurations/Mouse_Tool/python/<main script>
  Settings/Configurations/Mouse_Tool/javascript/<main script>
  Settings/Configurations/Utilities/JSON/injection_router.json
  Settings/Configurations/Wordlists/<the three wordlist JSONs>
The folder structure is created either way; only the files need to come from here.
