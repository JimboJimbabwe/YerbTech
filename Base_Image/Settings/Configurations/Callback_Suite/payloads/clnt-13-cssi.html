Reference: WSTG-CLNT-13
Scripts included via <script src> bypass the Same-Origin Policy — they execute in the including page's context. If the target script exposes sensitive data through global variables, function parameters, or prototype-accessible values, this page can intercept and display it.

Note: The target script runs in this origin's context. Cookies shown here are from this server, not the target — unless the target includes session data directly in the script body (JSONP, dynamic JS, etc.).
