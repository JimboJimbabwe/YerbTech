How it works:
Each generated file creates an invisible iframe over a clickable decoy element. If the target page loads inside the iframe, it means X-Frame-Options and Content-Security-Policy: frame-ancestors are not set or are misconfigured. Toggle iframe visibility with the button on the PoC page to confirm the overlay is aligned.

Evidence to collect:
Screenshot with opacity toggled showing target content loaded under the decoy. Also note the missing/permissive X-Frame-Options in the response headers.
Quick test headers to check
X-Frame-Options: should be DENY or SAMEORIGIN
Content-Security-Policy: should include frame-ancestors 'none' or frame-ancestors 'self'
If neither header is present → Vulnerable
